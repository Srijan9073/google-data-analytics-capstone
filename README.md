# Google Data Analytics Professional Capstone: Case Study

A comprehensive case study analyzing customer behavior to drive business strategy, completed as the capstone project for the **Google Data Analytics Professional Certificate**.

---

## 📌 Business Scenario
- **Objective:** Analyze historical user data to understand how casual riders and annual members use the service differently.
- **Business Goal:** Provide executive recommendations to convert casual riders into high-margin annual members.

## 🛠️ Methodology (The 6 Data Analysis Phases)
1. **Ask:** Defined the business task and stakeholder expectations.
2. **Prepare:** Assessed data integrity, schema structures, and data credibility.
3. **Process:** Cleaned messy data using SQL / Python (handled null values, standardized timestamp formats).
4. **Analyze:** Executed aggregations and trend calculations across seasonal, weekly, and hourly usage patterns.
5. **Share:** Designed visualizations in Tableau / Power BI to present findings to business stakeholders.
6. **Act:** Formulated 3 high-impact marketing recommendations based on data findings.

## 📂 Repository Contents
- `data/`: Dataset documentation and sample extracts.
- `sql/`: Cleaning and aggregation queries.
- `notebooks/`: Data transformation and exploratory analysis.
- `presentation/`: Final executive slide deck and dashboard links.
